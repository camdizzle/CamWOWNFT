## Key Differences from Free Mode

1. **Premium Race Info banner** showing live prize pool + split percentages
2. **Entry fee label** ("50 PBP") shown on each NFT card instead of just "click to join"
3. **Prize pool updates live** as more players join (e.g., 3 entries = 150 PBP)
4. **Season pool gauge** is visible on both modes but premium races actively grow it

## Notes

- PBP is paid at join time, refunded on withdraw
- No max racer cap — 10, 20, 50+ entries all valid
- After 2 hours of extensions, minimum drops to 3 (never cancels)
- Both modes still earn coins from placements + achievements
- Premium results show "+X PBP" column for top 3 only
